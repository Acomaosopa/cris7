ANIMACIÓN SIUUU - GITHUB PAGES

Archivos:
- index.html
- style.css
- script.js
- assets/jugador.svg (ilustración original proporcionada)

PRUEBA LOCAL:
Abre index.html en tu navegador. Para una prueba más fiel, puedes iniciar un servidor local desde esta carpeta.

PUBLICAR EN GITHUB PAGES:
1. Crea un repositorio en GitHub.
2. Sube TODOS los archivos y conserva la carpeta assets.
3. En el repositorio entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root), y guarda.
6. Espera la publicación y abre la URL que GitHub Pages te entregue.

No requiere npm, frameworks ni dependencias externas.
